# Pasta Utils (Utilitários)

## Responsabilidade
Pasta reservada para funções de apoio que são reutilizadas em múltiplas camadas do sistema (ex: utilitários de criptografia de senhas, geradores de data/hora, helpers de formatação ou validadores genéricos).

## Regras
- Deve conter apenas funções puras e utilitários que não possuem dependências diretas de lógica de negócio de módulos específicos.
